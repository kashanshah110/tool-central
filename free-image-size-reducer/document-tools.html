Document tool questions

Can I split a PDF into selected pages?

Yes. Enter individual page numbers or ranges, such as 1-3, 5, then save the selection as one PDF or as separate page files in a ZIP.

Does PDF to Word preserve the original formatting?

No. It extracts selectable text into a simple editable DOCX. It does not preserve the original layout, tables, fonts, or images, and scanned PDFs need OCR first.

How does Word to PDF work here?

Choose a DOCX file, review its browser preview, and select “Download PDF.” Common text, headings, lists, tables, and inline images are supported; advanced layout may differ from the original.

What can the PowerPoint size reducer optimize?

It can resize embedded JPEG and PNG images in modern PPTX files. It does not optimize legacy PPT files or other media types.
